# C++ Grade Calculation Program

## 📌 Overview
This C++ console program is part of my coursework at Rayong Technical College. It calculates a student's total score by combining midterm and final exam scores, and automatically assigns a letter grade based on predefined criteria using user-defined functions.

## 🛠️ Key Features & Functions
* **`void input()`:** Handles user input to collect Midterm (`m`) and Final (`f`) scores.
* **`int sum()`:** Computes and returns the total score by adding midterm and final scores together.
* **`char cal()`:** Evaluates the total score using conditional statements (`if-else`) and returns the appropriate letter grade (A, B, C, D, F, or E).
* **`void main()`:** Acts as the main controller, orchestrating the execution sequence (clear screen, get input, display sum, and display grade).

## Detail
* **Language:** C++
* **Concepts:** User-defined Functions, Return Values, Conditional Statements (`if-else`), Global Variables

## 🛠️ ฟังก์ชันและคุณสมบัติหลัก (Key Features & Functions)
* **`void input()`:** ทำหน้าที่รับค่าข้อมูลจากผู้ใช้เพื่อเก็บคะแนนสอบกลางภาค (m) และคะแนนสอบปลายภาค (f)
* **`int sum()`:** ทำหน้าที่ประมวลผลและคืนค่า (return) คะแนนรวมโดยนำคะแนนกลางภาคและปลายภาคมารวมกัน
* **`char cal()`:** ทำหน้าที่ประเมินคะแนนรวมโดยใช้คำสั่งเงื่อนไข (if-else) และคืนค่าเป็นเกรดตัวอักษรที่เหมาะสม (A, B, C, D, F, หรือ E)
* **`void main()`:** ทำหน้าที่เป็นฟังก์ชันหลักในการควบคุมลำดับการทำงานของโปรแกรม (เคลียร์หน้าจอ, เรียกฟังก์ชันรับค่า, แสดงผลคะแนนรวม และแสดงผลเกรด)
## Detail
* **ภาษาที่ใช้** C++
