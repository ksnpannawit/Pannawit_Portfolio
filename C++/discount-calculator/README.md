# C++ Discount Calculator Program

## 📌 Overview
This C++ console program calculates the discounted price and final payment based on the user's total price input. It demonstrates business logic and multi-tier conditional statements (`if-else if`).

## 🛠️ Key Features & Logic
* **User Input:** Takes the total price (`T_price`) from the user.
* **Discount Tiers (`if-else if`):** Evaluates the price range and applies different discount rates (0%, 5%, 10%, 15%, and 20%).
* **Calculation & Output:** Computes the discount amount and final price, then displays the result in the console.

## Detail
* **Language:** C++
* **Concepts:** Conditional Statements (`if-else if`), Arithmetic Operations, Basic Input/Output (`cin`/`cout`)
